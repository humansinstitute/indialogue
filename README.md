# In Dialogue

Native SwiftUI iPhone recorder, version 1.3 (build 8), for iOS 18+. Open `Recorder.xcodeproj` in Xcode 26.3 and select `PeteRecorder`.

The capture screen has a microphone preference control, a left menu and Start recording. During capture it shows the actual input, elapsed time, a live recording level history and Stop and save. The microphone picker requests permission and discovers iOS-supported inputs when opened. A preference is used when available; the actual capture route remains authoritative. Recordings, notices, identity and vocabulary live in the menu. Important audio failures also show an alert.

Explicit Stop and save queues transcription with the **installed speech model only**. iOS 26 SpeechAnalyzer/SpeechTranscriber requires a supported device/language. Missing models or speech failures leave durable status on the recording and retain audio. Manual retry, explicit model download and cancellation remain available. The queue recovers on launch/foreground, yields to new capture, and defers when the app is suspended. Background transcription is best effort; iOS does not promise unlimited execution. The app never removes Apple-managed speech models.

Tap a linked word in transcript review to replace that occurrence and optionally teach reusable vocabulary. Vocabulary settings supports adding, editing and removing word/phrase corrections. Deterministic replacement uses whole word/phrase boundaries, preserves surrounding punctuation, adapts capitalization and avoids cascading replacements. No sample correction is enabled by default. Original speech text is retained separately from edited text. Optional **Clean up on device** uses iOS 26 Apple Intelligence through [Foundation Models](https://developer.apple.com/documentation/FoundationModels/generating-content-and-performing-tasks-with-foundation-models). Its availability is separate from speech model installation. Bounded chunks use fresh sessions and relevant saved correction/name hints; cleanup has no cloud fallback. Output is an untrusted draft with explicit accept/reject. Review names, numbers and meaning before accepting.

Identity settings imports a checksum/scalar-validated Bech32 `nsec` and a 4–12 digit PIN through secure fields. A two-part local vault encrypts the secret scalar with AES-256-GCM. PBKDF2-HMAC-SHA256 uses 210,000 iterations, a random 16-byte salt, and `PIN:base64(32-byte installation secret)`. Only that installation secret goes in recorder-specific, non-synchronizing, when-unlocked/device-only Keychain storage; ciphertext lives in backup-excluded Application Support/Identity. PIN and plaintext keys never go in preferences, files or logs. Wrong PIN does not reset the vault. Import cannot overwrite an existing vault; removal/replacement is explicit and leaves recordings untouched. Explicit Lock/removal clears the vault's in-memory secret. An authenticated identity stays unlocked across inactive/background/foreground for the app process lifetime; cold process launch requires PIN again. PIN and plaintext key are never persisted. Swift/runtime temporary copies cannot be guaranteed to be physically erased. The unlocked vault derives the public Nostr npub and signs NStack authentication and message instructions locally with pinned swift-secp256k1 0.23.2; plaintext keys never reach the transport.

When an imported identity is locked, launch and foreground present a focused PIN unlock screen. Unlock resumes eligible paused uploads; failed uploads still require explicit retry. Continue locked keeps recording available and suppresses another prompt until the next background/foreground cycle. Menu → Identity remains available for management.

Capture intent and each segment path are written atomically before capture begins. Mono AAC segments last up to 15 seconds; small boundary gaps are possible. Recovery retains UUIDs, earlier audio and unreadable segment references. Corrupt manifests are isolated and reported without deleting audio. Playback and combined `.m4a` sharing omit unreadable segments with a notice. Interruption, lost input, encode/write errors or storage below a 20 MB reserve stop capture and preserve earlier segments. Force quit, reboot, full storage and OS termination do not guarantee continued capture or final-segment recovery.

Audio, original/edited transcripts, drafts, vocabulary and recording metadata live in Application Support/Recordings, excluded from device/iCloud backup. Deleting the app deletes the library. **Update in place with the same bundle ID and signing identity; never uninstall/reset to update.** Export important recordings with Share and keep your own identity backup. NStack setup is opt-in. Saved automatic-upload configuration applies only to new recordings; existing recordings require explicit Upload. Full corrected transcripts and complete audio are delivered to private workspace storage and a selected channel with the saved custom prompt. Delivery pauses for recording, background or locked/mismatched identity. See [NStack integration](docs/INTEGRATION.md) for retries and retention limits. Explicit speech-model download may contact Apple; Apple manages its models and updates.

See [installation](docs/INSTALLATION.md), [validation](docs/VALIDATION.md), and [NStack integration](docs/INTEGRATION.md).

Microphone startup allows up to one second for an available preferred input to become the actual route. iOS remains authoritative; fallback/pending preference is recorded in diagnostics. Routine route notifications update the screen without an alert; only distinct actual input/data-source changes are logged. Lost input and interruptions still stop capture with a warning. The ten-second level history reads the existing AAC recorder at 4 Hz, continues across segments, clears on stop/foreground, and suspends metering while background capture continues. Reduce Motion shows a single current level; VoiceOver exposes a qualitative level without live announcements.

Menu → Settings offers **Automatically delete recordings**, disabled by default, with a saved whole-day period from 1 to 3650 (initial value 30). Saving an enabled policy applies to existing recordings too: export anything important first. Age uses elapsed 24-hour days from recording creation, not last edit/upload. Local recording folders (audio, metadata, original/edited transcripts and drafts) and finished local upload snapshots and their transcript-bearing delivery entries are removed; uploaded workspace objects/messages remain. No cloud deletion is requested. Failed, paused, queued or active uploads, automatic upload intents, queued/running transcription, cleanup, capture and playback defer deletion safely. Unreadable upload ledgers and unavailable protected data prevent automatic deletion. Failures appear in Settings and retry at a later safe check. Checks run on launch/foreground, protected-data availability, and safe capture/playback/job completion; iOS does not run this cleanup while the app is closed.
